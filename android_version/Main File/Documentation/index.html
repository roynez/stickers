Android Application Setup

Requirements

  1. Android Studio 3.5.3 :Download

Configuration

  1. Open Android Application into Android Studio
  2. Change package name in application
  3. Change Application Name
  4. Change Application Icon
  5. Change Server URL
  6. Create Firebase Account
  7. SetUp One Signal Notification
  8. Setup AdMob

A). Open Android Application into Android Studio

Step 1: Open Android Studio -> Open your project by clicking on "Open an existing Android Studio Project"

Step 2: Select your downloaded project folder

B). Change package name in application

Step 1: After opening project , Click on setting icon as shown in below image

Step 2: Unckeck "Compact Middle Packages" option

Step 3: Right click on wxsticker -> Click on Refactor -> Click on Rename

Step 4: Click onRename Package from the popup.

Step 5: Write your package name -> Select both the checkbox as shown in below image -> Click on Refactor

Congratulations.. You successfully changed package name.

C). Change Application Name

Step 1: Click on res

Step 2: Click on values -> Click on strings.xml

Step 3: Click on Replace Sticker with your application name as shown in below image

Step 4 (Optional): Change other string as you change in step-3 if you want.

C). Change Application Icon

-> Click on res

-> Click on New

-> Click on Image Asset

-> Select Your App Icon

-> Select Yes

-> Click on Next button.

-> Click on res

-> Click on Finish button.

Congratulations.. You have successfully changed your application icon.

D). Change Server URL

Step 1: Click on java

Step 2: Click on wxsticker

Step 3: Click on constant

Step 4: Change your server URL as shown in below image

E). Create Firebase Account

NOTE : We must setup firebase to setup OneSignal notification in app that is discussed in next topic.

Step 1: Open Firebase Console and login Firebase Console

  • ➣ Click on Create a project

Step 2:

  • ➣ Write your project name
  • ➣ Click on Continue
  • ➣ Turn off Enable Google Analytics for this project
  • ➣ Click on Create project
  • ➣ Your new project now ready. Click on Continue

Step 3: Register Your Android application into firebase

  • ➣ Click on Android
  • ➣ Enter your android application package name.
  • ➣ Click on Register app
  • ➣ Click on Next
  • ➣ Click on Next
  • ➣ Click on Skip this step

Step 4: How to get Server key and Sender ID

  • ➣ Click on Setting Icon -> Click on Project Setting
  • ➣ Click on Cloud Messaging Tab
  • ➣ Copy the Server Key (We will use this ServerKey in OneSignal notification setup)
  • ➣ Copy the Sender ID (We will use this SenderID in OneSignal notification setup)

F). Setup One Signal Notification

Step 1: Open this link https://app.onesignal.com/login.

Step 2: Sign In or Sign Up. After successfully SignIn, You get the following Home screen.

Step 3: Click on ADD APP button.

Step 4: You will get the popup and Enter name of your app.

Step 5: Click on CREATE button.

Step 6: Now select Google Android as platform.

Step 7: Click on NEXT” button.

Step 8: Paste the Firebase Server Key from Firebase. Get ServerKey

Step 9: Click on SAVE button.

Step 10: Select Native Android as target SDK.

Step 11: Click on NEXT button.

Step 12: Now you can see APP ID. Copy this APP ID.

Step 13: Now paste that APP ID as shown in following image.

  • ➣ Click on Gradel Scripts
  • ➣ Click on bundle.gradle
  • ➣ Paste your OneSignal APP ID
  • ➣ Click on Sync Now button.
  • ➣ Run application in your real device
  • ➣ Once run in your phone, click on Check Subscribed User button
  • ➣ Click on Done button.

Congratulations! You have successfully implemented OneSignal Notification.

G). Setup AdMob


Step 1: Click on Apps.

Step 2: Click on ADD APP button.

Step 3: Click on NO button.

Step 4: Enter your app name.

Step 5: select Android as a platform.

Step 6: Click on ADD button.

Step 7: Now click on CREATE AD UNIT button.

Step 8: Now click on SELECT button under Intrestial section.

Step 9: Enter Ad Unit Name.

Step 10: Click on CREATE AD UNIT button.

Step 11: Now copy App ID and Interstitial Ad ID.

Step 12: Now paste Interstitial Ad ID in String.xml file as shown in following image.

  • ➣ Click on res
  • ➣ Click on values
  • ➣ Paste your strings.xml
  • ➣ Now paste your APP ID and Intrestial Ad ID as shown in following image.

    • Congratulations. You have successfully done with AdMob setup.
