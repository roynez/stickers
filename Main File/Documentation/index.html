A). Open iOS Application into Xcode

Step 1: Open project by double clicking on Sticker.xcworkspace file as show in below image. ( Note : Don’t open “Sticker.xcodeproj” file.)

B). Add Apple ID to Xcode

Step 1: After opening project , Click on Xcode that on left-top side of the screen.

Step 2: Click on Preferences from submenu as shown in below image.

Step 3: Now click onAccounts.

Step 4: Click on+ button as shown in following image.

Step 5: Now selectApple ID.

Step 6: Click onContinue button as shown in following image.

Step 7: Now enter your Apple ID and password and click onNEXT button as shown in following image. Now you can see your account in list.

C). Basic Configuration

Step 1: Click onSticker.

Step 2: Click onGeneral tab as shown in following image.

Step 3: Now setDisplay Name that you want to show on phone screen when user install your application.

Step 4: SetVersion as “1.0”

Step 5: SetBuild as “1.0”

Step 6: SelectAutomatically manage Signing option and select your team.

D). How to Set an Application Icon?

Note : Right now its optional but its is necessary to change app icon to your app icon while uploading your application on store.

Step 1: Click on -> button under App Icons Source section as shown in following image. You need to upload .appiconset type here. Follow below step to make .appiconset file.

Step 2: First create your icon as you want. But your icon must be in .png format and it must of 1024x1024 dimension.

Step 3: Now Open https://makeappicon.com/ and upload your icon’s .png file and wait for some time.

Step 4: Now write your Email ID in which you want to receive icon that can be set in application and click on download button.

Step 5: After some time you will receive mail. So download that zip file and unzip it.

Step 6: Now click on ios folder and find a folder named AppIcon.appiconset as shown in following image.

Step 7: Now drag that folder and drop into the project file as shown in following image.

F). Setup One Signal Notification

Step 1: Open this link https://app.onesignal.com/login.

Step 2: Sign In or Sign Up. After successfully SignIn, You get the following Home screen.

Step 3: Click on ADD APP button.

Step 4: You will get the popup and Enter name of your app.

Step 5: Click on ADD APP button.

Step 6: Now select Apple iOS as platform.

Step 7: Click on NEXT” button.

Step 8: Click on Choose File button and upload .p12 file that we created before while making certificate. How To Generate .p12 file?

Step 10: Select Native iOS as target SDK.

Step 11: Click on NEXT button.

Step 12: Now you can see APP ID. Copy this APP ID.

Step 13: Now click on x button to close this popup. Then click on LEAVE SETUP button.

Step 14: Now paste APP ID in Config.swift file as shown in following image.

Congratulations! You have successfully done with OneSignal Notification.

H). Create Certificate

I). Certificate Signing Request

Step 1: At left top side , click on Keychain Access.

Step 2: Click on Certificate Assistance from the menu.

Step 3: Click on Request a Certificate from Certificate Authority from the sub menu.

Step 4: Enter User Email Address.

Step 5: Enter common name as you want.

Step 6: Then select Save To Disk option.

Step 7: Click on Continue.

Step 8: It will ask you for storing this file. So give name of the file as you want and save it on Desktop.

Step 9: Click on Done” button.

II). Register App Identifier

Step 1: Click on Certificates, Identifiers and Profiles.

Step 2: Click on Identifiers.

Step 3: Click on + button. You can see following screen as result.

Step 4: Select App IDs.

Step 5: Click on Continue button.

Step 6: Select iOS as a Platform.

Step 7: Click on Continue button.

Step 8: Select App IDs.

Step 9: Click on Continue button.

Step 10: Select App IDs.

Step 11: Click on Continue button.

III). Generate Certificate

Step 1: Click on Certificates on the left side.

Step 2: Click on + button.

Step 3: Select Apple Distribution option.

Step 4: Click on Continue button.

Step 5: It is asking you to upload a Certificate Signing Request. So upload .certSigningRequest file here that we made before.

Step 6: Then click on “Continue” button. It will show you following screen.

Step 7: Click on Download button.

Step 8: Your certificate is generated successfully. Now go to Download folder and double click on that distribution.cer file to install that distribution.cer file in Keychain Access utility.

Step 9: Once you double click on that file it will be installed in Keychain Access utility. So open Keychain Access utility.

Step 10: Click on Login tab that is on left side.

Step 11: Click on Certificates tab. It will show your file installed at right side. You can find your file by name or expires date.

IV). Generate Push Notification Certificate

Step 1: Click on Certificates on the left side.

Step 2: Click on + button.

Step 3: Select “Apple Push Notification service SSL (Sandbox and Production)” option from the services.

Step 4: Click on Continue button.

Step 5: It is asking you to select your AppID that you made before. So select your AppID.

Step 6: Click on Continue button.

Step 7: It is asking you to upload a Certificate Signing Request. So upload “.certSigningRequest file here that we made before.

Step 8: Click on Continue button.

Step 9: Click ob Download button.

Step 10: Your notification certificate is generated successfully.Now go to Download folder and double click on that aps.cer file to install that aps.cer file in Keychain Access utility.

Step 11: Once you double click on that file it will be installed in Keychain Access utility. So open “Keychain Access utility.

Step 12: Click on Login tab that is on left side.

Step 13: Click on Certificates tab. It will show your file installed at right side. You can find your file by name or expires date.

Step 14: Now find your file and right click on that file.

Step 15: Click on Export ** as shown in image and save this .p12 file with suitable name.

(NOTE : This “.p12” fill will be needed when you setup your application for One Signal Notification.)

V). Generate Provisional Profile

Step 1: Click on Profiles on the left side.

Step 2: Click on + button.

Step 3: Select App Store option under Distribution section.

Step 4: Click on Continue button.

Step 5: It is asking you to select your AppID that you made before. So select your AppID.

Step 6: Click on Continue button.

Step 7: It asking you to select certificate. So select your certificate that you recently created.

Step 8: Click on Continue button.

Step 9: It will ask you for entering profile name. So enter name as you want.

Step 10: Click on Generate button. Then click on “Download” button.

Step 11: Your profile is generated successfully. Now go to “Download” folder and double click on that .mobileprovision file.

Step 12: Click on Add to Library to install that “.mobileprovision” file in “IPhone Configuration Utility”.

Step 13: Once you click on Add to Library, it will be installed in IPhone Configuration Utility. So open IPhone Configuration Utility.

Step 14: Click on Provisioning Profiles that is on left side. So you can see list of profiles at right side. You can also see your profile in this list. You can find your file by name or expires date.
